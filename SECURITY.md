# Security Policy

## Scope
This repository is published as a research prototype and predictive simulation framework for football data. 

**This is strictly an educational tool.** 
It should not be directly plugged into financial, proprietary, or automated betting pipelines without stringent local security and infrastructure auditing.

## Reporting a Vulnerability
If you discover a vulnerability or accidental exposure of credentials in the history of this repository:
- Please **do not** open a public issue.
- Reach out privately via the author's GitHub profile contact details.

Vulnerability reports will be handled with discretion and promptly mitigated.
